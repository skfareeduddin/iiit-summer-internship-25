#  Task 1: YOLOv8 Segmentation Test on Online Image

##  Objective
Verify YOLOv8 environment setup by performing object detection and segmentation on an online image.

##  Tools & Libraries Used
- Python  
- Ultralytics YOLOv8  
- Pretrained model: `yolov8n-seg.pt`

##  Steps Performed
- Installed necessary packages and set up the environment  
- Loaded the YOLOv8 segmentation model  
- Performed inference on an image from a URL (`bus.jpg`)  
- Saved and displayed the output image with segmentation results

##  Output
- Output image shows objects detected and segmented with masks  
- Demonstrates successful setup and basic functionality of YOLOv8 segmentation
