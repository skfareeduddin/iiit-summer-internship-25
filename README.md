# iHub-Data, IIIT Hyderabad Summer Internship 2025

This repository contains my work completed during the **Summer Internship 2025** at **iHub-Data, IIIT Hyderabad**. The internship focused on hands-on experience with **Ultralytics YOLOv8** for object detection and segmentation tasks using real-world and custom datasets.

Each task involved solving practical computer vision problems, ranging from basic segmentation to full model training, with a strong emphasis on dataset preparation, annotation, and evaluation.

---

## 🔧 Technologies Used
- Python  
- Ultralytics YOLOv8  
- PyTorch  
- CUDA (for GPU-accelerated training)
- ffmpeg (external, for video frame extraction and stitching)

---

## 📁 Task Overview

| Task | Description |
|------|-------------|
| [Task 1](./task1/) | Run YOLOv8 segmentation on a sample image from the web |
| [Task 2](./task2/) | Perform segmentation on custom images and video frames |
| [Task 3](./task3/) | Fine-tune YOLOv8 on a wildlife dataset |
| [Task 4](./task4/) | Train YOLOv8 on a self-annotated dataset and run inference on a test video |
| [Task 5](./task5/) | Detect Diabetic Foot Ulcers (DFU) using a YOLOv8 model trained on annotated medical images |
